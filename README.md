# Цель проекта

Реализация функционального калькулятора в рамках итогового задания по модулю Git. Проект демонстрирует:

- Работу с системой контроля версий Git (ветвление, rebase, патчи)
- Применение актуальных практик при работе с репозиториями
- Современные подходы к разработке React-приложений

# Решаемая задача

Создание калькулятора с поддержкой основных арифметических операций, отображением истории вычислений и результатом в реальном времени.

# Ключевые требования

- Поддержка операций: +, -, \*, /, %
- Отображение истории вычислений
- Визуализация результата с помощью Ant Design
- Чистая история Git с применением патчей

# Запуск проекта

### Требования

- node.js версия 16+
- npm или yarn

### Инструкция по устрановке

1. Клонируйте репозиторий:
   `git clone https://github.com/vozmitelvlas/Calculator.git`
2. Установите зависимости
   `npm install #или yarn install`

3) Запустите проект в режиме разработки:
   `npm run dev # или yarn dev`
4) Откройте в браузере
   [http://localhost:5173](http://localhost:5173)

### Сборка для продакшена

`npm run build #или yarn build`
